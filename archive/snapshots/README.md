# Archived meeting pages

Captured November 3, 2026 from the targets linked on `archive/index.html`.

All 88 distinct linked targets were saved: 75 under `www.rrb.wayne.edu/MTS/` and 13 on other hosts. Repeated links share the same saved file. The archive page now uses the local copies for the former group and retains the original link plus an “archive version” link for the latter.

`manifest.json` records source URLs, redirects, content types, local filenames, source and stored-file checksums, and download failures for supporting files.

These are static copies. Executable scripts and inline event handlers are removed. Available stylesheets, images, fonts and supporting meeting documents are included, with references rewritten to local paths. Other links point back to their original hosts. Several original supporting files return 404/503 errors or block downloads; those references remain external. The saved pages therefore preserve accessible content but are not guaranteed to function entirely offline. Forms, maps, search and other live features may still depend on the original websites.

The Stolzfest landing page blocked direct HTTP downloads but loaded in the browser. Its HTML was captured from the loaded document, then processed as a static snapshot. Its supporting pages and some theme assets blocked downloads and remain external.

No wording or layout on the main archive page was changed beyond the requested link replacements and added “archive version” links. The rest of the website was left as found.
